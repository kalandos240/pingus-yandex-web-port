# Contributing

Спасибо за интерес к Web/Yandex-порту Pingus.

Главная цель проекта — сохранить оригинальную игру и сделать её стабильной в браузере и на Яндекс Играх. Поэтому изменения должны быть небольшими, объяснимыми и легко проверяемыми.

## Перед изменениями

Проверь, к какой категории относится задача:

- **browser/runtime** — Canvas, Emscripten, SDL, аудио, ввод, focus/pause;
- **Yandex Games** — SDK, Game Ready, Gameplay API, реклама, Player Data;
- **localization/content** — RU/EN, tinygettext, доступные уровни и публичные строки;
- **performance** — renderer, minimap, большое количество пингусов;
- **gameplay/source** — изменения непосредственно поведения оригинальной игры.

По возможности не смешивай несколько категорий в одном патче.

## Общие правила

1. Не переписывай оригинальную механику без необходимости.
2. Не меняй оригинальную графику только ради «улучшения» внешнего вида.
3. Любой Web-specific workaround должен быть ограничен Web/Emscripten-сборкой, если это возможно.
4. Не добавляй inline JavaScript/inline event handlers в финальную HTML-оболочку.
5. Yandex SDK должен оставаться необязательным для локального запуска: если SDK недоступен, игра должна продолжать запускаться с локальными сохранениями.
6. Изменения сохранений не должны стирать более продвинутый существующий прогресс.
7. Новые player-facing строки должны иметь русский вариант или быть исключены из релизной Web-конфигурации.

## Проверки перед merge

Минимально необходимо убедиться, что:

- проект компилируется;
- итоговый ZIP создаётся;
- browser smoke test доходит до первого кадра;
- сохранение восстанавливается после reload;
- `index.html` не содержит запрещённых inline-обработчиков после CSP postprocess;
- локализационные и content-аудиты проходят;
- изменения рекламы не могут открыть interstitial во время активного уровня.

## Commit style

Рекомендуемые префиксы:

```text
feat: новая возможность
fix: исправление ошибки
build: изменение build pipeline
perf: оптимизация
localization: переводы
content: релизный контент
ci: CI / smoke tests
docs: документация
```

Пример:

```text
fix: restore gameplay after Yandex interstitial
```

## Pull requests

В описании PR укажи:

- что было не так;
- что изменено;
- почему изменение безопасно для оригинального Pingus;
- как проверено;
- влияет ли оно на Yandex SDK, сохранения, рекламу или локализацию.

Если изменение визуальное, желательно приложить скриншот или короткое видео до/после.

## Лицензирование

Не удаляй юридические материалы оригинального проекта из release pipeline. Готовая распространяемая сборка должна сохранять необходимые license/source материалы.
